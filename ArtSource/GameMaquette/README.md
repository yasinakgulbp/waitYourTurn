# Game-sized architectural maquette trial

Native Blender source and offline vertex AO; preserves the existing game train
openings and bounds. This is a Survival art candidate, not visual approval or
mobile performance acceptance. All designs are original; reference screenshots
are not pasted onto surfaces. Original D48 input is unchanged.

Rebuild: Blender --background --factory-startup --python
Tools/TrainArt/build_game_maquette.py. Use -- --no-render to skip the offline
Cycles preview. Actual Unity appearance: docs/generated/maquette-unity-preview.png.
Details, dimensions, installation, test receipts: docs/MAQUETTE_ART.md.
