# waitYourTurn

Mobil zombi savunma oyunu: istasyonlar arasında yolculuk eden bir trende hayatta kalma, rastgele vagon ataması ve geliştirilebilir savunmalar.

[Geliştirme belgeleri ve güncel durum](docs/README.md): oyun tasarımı, mimari, kararlar ve aşamalı yol haritası.

Yeni bir geliştirmeye başlamadan önce belgelerdeki güncel kararlar, aşama durumu ve Git çalışma ağacı birlikte kontrol edilir.
